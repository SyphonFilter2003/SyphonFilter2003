## 🚀 Projetos em destaque

### 🔗 API REST Analítica — Gestran *(produção)*
API de acesso controlado a dados analíticos da plataforma Gestran.  
Cada cliente enxerga apenas os próprios dados, com autenticação integrada ao sistema externo OpenFleet.

- +80 endpoints gerados dinamicamente via `table_registry.py`
- Autenticação OAuth2 + isolamento de dados por cliente (`grupoid`)
- Rate limiting, allowlist de e-mails e filtros obrigatórios por data
- Manutenção ativa: diagnóstico via SQL, correções e deploy sem downtime

`Python` `Flask` `PostgreSQL` `JWT` `REST`

---

### 🏋️ Plataforma SaaS — Gestão de Personal Trainers e Alunos
Plataforma web multi-perfil construída do zero: Personal Trainer, Aluno e Administração.

- Design system próprio com CSS modular (sem conflitos globais, sem `!important`)
- Dashboards analíticos com Recharts (AreaChart, gradientes, tooltips customizados)
- Calendário 100% customizado em React com navegação mensal e eventos por dia
- Responsividade completa com `clamp()` e breakpoints em 1440px, 1280px, 1024px e 768px

`React` `TypeScript` `CSS Grid` `Recharts`
